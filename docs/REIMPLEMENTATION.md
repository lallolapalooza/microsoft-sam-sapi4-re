# Reimplementation guide

Two layers:

1. **Exact, fully specified:** container + Inventory + unit record decoding.
2. **DSP:** needs a port of the routines in `ENGINE_ARCHITECTURE.md` §4–5.
   Until then, use the bundled engine oracle as ground truth.

## 1. Container

Use any CFB/OLE reader (`olefile` in Python). Read the `Inventory` stream.
`sam.vce` is 1 623 552 bytes; `Inventory` is 1 395 733 bytes.

## 2. Inventory parser (reference pseudocode)

```python
pos = 0
rate, feat, nA, nB, nC, fft, aux = u32x7()
A = [matrix() for _ in range(nA)]   # 6
B = [matrix() for _ in range(nB)]   # 11
C = [matrix() for _ in range(nC)]   # 13
count, bytes_ = u32x2()
off = u32x(count + 1)
base = pos + 4 * (count + 1)
assert base + (bytes_ - 4 * (count + 1)) == len(inv)

def matrix():
    r, c = u32x2()
    return r, c, f32x(r * c)

def unit(i):
    a = off[i]
    b = off[i + 1] if i + 1 <= count else bytes_ - 4 * (count + 1)
    return inv[base + a: base + b]
```

Unit indices are `1..count`. `off[0] == off[1] == 0`.

## 3. Unit decoder

```python
def decode_unit(rec):
    n = u32(rec, 0)
    pitch, used = decode_pitch(rec[4:], n)
    p = 4 + used
    idx = rec[p:p + 6*n]; p += 6*n
    gains = f32x(n, rec, p); p += 4*n
    extras = []
    for f in range(n):
        if pitch[f] > 0:
            k = 11 if (f == 0 or pitch[f-1] <= 0) else 13
            extras.append(rec[p:p+k]); p += k
        else:
            extras.append(b'')
    assert p == len(rec)
    return n, pitch, idx, gains, extras
```

`decode_pitch` is the loop in `FORMAT_SAM_VCE.md` §3.5 with `base = 0`.
`nSamples = sum(abs(int(v)) for v in pitch)`.

Codeword indices:
* `idx[f*6 + a]` indexes row `idx` of `A[a]` (dimensions 3,3,3,3,4,4).
* For voiced frame `f`, `extras[f]` indexes `B` (11 bytes) or `C` (13 bytes)
  in the same order.
* All indices are `< matrix.rows`; verified for all units.

## 4. Audio synthesis

`FUN_636719FA` is the reference implementation. A port must reproduce:

1. `FUN_63678470`: feature conditioning (fix-up `FUN_63688708` if the sequence
   is not monotonic, then cosine/cepstral/window transform using tables from
   `FUN_636850C0`/`FUN_63685172`).
2. `FUN_63684B60`: 512-point split-radix FFT/IFFT with the engine’s twiddle
   tables. Float32/float80 details matter for bit-exactness.
3. `FUN_6368874C` / `FUN_636887A7`: group-B/group-C spectral reconstruction.
4. `FUN_636886C6`: multiply every sample by `gain`.
5. `FUN_6368864B`: overlap-add with the previous frame (`hop = |pitch|`).
6. Unvoiced frames: `noise[phase++] * gain * 0.02`, `noise` being the
   `inventory+0x3C` buffer generated by `FUN_63675D45` (Gaussian, `rand()` seed 1).

`state` (third argument) carries the running noise phase at `+0x20` and flags
at `+0x24`. Zeroing it yields isolated-unit rendering, which is what the
archive contains.

## 6. Known unknowns

* Meaning of the four `Senone` floats beyond “prototype vector”.
* `AltUnits`/`TreeImage` selection semantics (unit→phone mapping is not stored
  in unit records).
* Header fields `20`, `512`, `9` beyond their observed use as feature
  dimension, FFT size and table size.
* Exact high-level DSP math inside `FUN_63678470` and `FUN_63684B60`; the
  decompiled C is available in `mstts.json`, and the engine itself can be used
  as the parity oracle.
